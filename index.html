대수의 법칙

같은 실험을 충분히 많이 반복하면, 관찰된 결과의 평균이 실제 기대값에 가까워진다는 확률 이론

E[Y] ≈ 1N ∑ y(i)

이론적 의미

표본평균은 반복 횟수 N이 커질수록 기대값에 가까워지고, 표본평균의 표준오차는 아래 공식으로 계산된다.

표준오차 SE = σ / √N

따라서 N이 커질수록 표준오차가 작아진다. N을 4배로 늘리면 SE는 약 1/2이 된다.

핵심 지표

실험은 단순히 수익률이 높은 조합이 아니라, 위험 대비 수익이 좋은 조합을 찾는 과정이다.

1

비중

각 자산에 투자하는 비율이다. 모든 비중을 더하면 100%가 되어야 한다.

2

기대수익률

해당 비중 조합에서 기대할 수 있는 평균 수익률이다.

3

변동성과 공분산

변동성은 수익률의 흔들림이고, 공분산은 자산들이 함께 움직이는 정도다. 둘 다 포트폴리오 전체 위험 계산에 필요하다.

4

샤프지수

위험을 감수한 만큼 수익을 얼마나 얻었는지 보여주는 지표다.

Sharpe = (Rp - Rf) / σp

해석 기준

같은 수익률이라면 변동성이 낮을수록 좋고,
같은 위험이라면 수익률이 높을수록 좋다.

그래서 이 예시에서는 샤프지수가 가장 높은 조합을 효율적인 포트폴리오로 본다.

코드 설명

전체 코드 흐름

import yfinance as yf # 주식 데이터를 가져오는 라이브러리
import random # 무작위 숫자를 생성하는 라이브러리
import math # 수학 함수 라이브러리
import matplotlib.pyplot as plt # 그래프를 그려주는 라이브러리
import matplotlib

# 재현성을 위한 seed 설정
# 같은 코드와 같은 데이터에서는 항상 같은 시뮬레이션 결과가 나오도록 함
random.seed(42)

# 분석할 한국 주식 종목과 티커(종목코드) 목록
# .KS = 코스피 종목
tickers = {
    "삼성전자": "005930.KS",
    "SK하이닉스": "000660.KS",
    "KODEX200": "069500.KS",
    "카카오": "035720.KS",
}

ticker_list = list(tickers.values())   # yifinance에 넘겨줄 티거 코드 리스트
name_list   = list(tickers.keys())     # 결과 출력용 종목 리스트

# yfinance로 2년치 주가 데이터 다운로드
raw_data = yf.download(ticker_list, start="2022-01-01", end="2024-12-31", auto_adjust=True)
price_data = raw_data["Close"]         # 종가(Close)만 사용

# 일일 수익률 = (오늘 가격 - 어제 가격) / 어제 가격
returns = price_data.pct_change().dropna() # 전날 대비 변화율을 자동으로 계산

print(returns.tail(3)) # 확인용
def get_random_weights(n):
    """
    n개의 종목에 무작위로 비중을 배분하는 함수
    예) n=4이면 [0.3, 0.2, 0.4, 0.1] 같은 리스트 반환
    모든 비중의 합은 반드시 1.0 (100%)이 됩니다
    """
    raw = [random.random() for _ in range(n)] # 0~1사이 난수 n개 생성
    total = sum(raw)  #전체 합 계산
    weights = [w / total for w in raw] # 전체 합으로 각 값을 나눠 비중 계산
    return weights


def calc_portfolio_return(weights, returns_df, ticker_list):
    """
    주어진 비중(weights)으로 포트폴리오의 연간 예상 수익률 계산
    수익률 = 각 종목의 평균 일일수익률 × 비중 × 252 (1년 거래일수)
    """
    portfolio_return = 0
    for i, ticker in enumerate(ticker_list):
        mean_daily_return = returns_df[ticker].mean()   # 종목의 일별 수익률 평균값 계산
        portfolio_return += mean_daily_return * weights[i] #수익률*비중->포트폴리오 수익률 계산
    portfolio_return *= 252   # 연간 수익률로 환산
    return portfolio_return  # 계산된 연간 수

def calc_portfolio_volatility(weights, returns_df, ticker_list):
    """
     종목 간 공분산까지 반영하여 트폴리오의 연간 변동성(위험) 계산
    """
    n = len(ticker_list)
    variance = 0.0 # 분산을 0에서 시작해 누적

    for i in range(n):
        for j in range(n):
            # 두 종목 간의 공분산 계산
            cov = returns_df[ticker_list[i]].cov(returns_df[ticker_list[j]])
            variance += weights[i] * weights[j] * cov # 비중 × 비중 × 공분산을 누적

    variance *= 252                    # 연간 변동성으로 환산
    volatility = math.sqrt(variance)   # 제곱급 씌워 -> 표준편차 = 변동성로 변환
    return volatility
def calc_sharpe_ratio(portfolio_return, volatility, risk_free_rate=0.03):
    """
    샤프지수 계산
    샤프지수 = (포트폴리오 수익률 - 무위험 수익률) / 변동성

    무위험 수익률: 위험 없이 얻을 수 있는 수익률 (예: 국채 금리)
    샤프지수가 높을수록 위험 대비 수익이 좋다는 뜻!
    """
    if volatility == 0:
        return 0
    sharpe = (portfolio_return - risk_free_rate) / volatility
    return sharpe
NUM_SIMULATIONS = 10000   # 시뮬레이션 횟수 (많을수록 정확하지만 느려짐)
n_assets = len(ticker_list)

# 결과를 저장할 빈 리스트들
all_returns     = []   # 각 시도의 수익률
all_volatility  = []   # 각 시도의 변동성
all_sharpe      = []   # 각 시도의 샤프지수
all_weights     = []   # 각 시도의 비중

# 샤프지수 갱신 추적을 위한 리스트
sharpe_history_iterations = [] # 몇 번째 시뮬레이션인지 기록
sharpe_history_max_sharpe = [] # 그 시점까지의 최대 샤프지수 기록
current_max_sharpe = -float('inf') # 현재 최대 샤프지수 (-무한대로 초기화 → 첫 값이 무조건 갱신되도록)

update_interval = max(1, NUM_SIMULATIONS // 100) # 업데이트 간격 설정 (예: 100번 시뮬레이션마다 기록)
for i in range(NUM_SIMULATIONS):
    weights = get_random_weights(n_assets)                    # 무작위 비중 생성
    ret     = calc_portfolio_return(weights, returns, ticker_list)    # 수익률 계산
    vol     = calc_portfolio_volatility(weights, returns, ticker_list)  # 변동성 계산
    sharpe  = calc_sharpe_ratio(ret, vol)                     # 샤프지수 계산

    all_returns.append(ret)        # 결과 저장
    all_volatility.append(vol)
    all_sharpe.append(sharpe)
    all_weights.append(weights)

    if sharpe > current_max_sharpe:   # 현재 샤프지수가 기존 최대보다 크면
        current_max_sharpe = sharpe   # 최대값 갱신

    if (i + 1) % update_interval == 0:                        # update_interval 배수마다
        sharpe_history_iterations.append(i + 1)               # 현재 시뮬레이션 횟수 기록
        sharpe_history_max_sharpe.append(current_max_sharpe)  # 현재 최대 샤프지수 기록

    if (i + 1) % 2000 == 0:                         # 2000번마다 진행 상황 출력
        print(f"  {i + 1}/{NUM_SIMULATIONS}")
max_sharpe_idx     = all_sharpe.index(max(all_sharpe))        # 샤프지수가 가장 높은 시뮬레이션 번호
max_sharpe_weights = all_weights[max_sharpe_idx]              # 해당 시뮬레이션의 비중
max_sharpe_return  = all_returns[max_sharpe_idx]              # 해당 시뮬레이션의 수익률
max_sharpe_vol     = all_volatility[max_sharpe_idx]           # 해당 시뮬레이션의 변동성

min_vol_idx     = all_volatility.index(min(all_volatility))   # 변동성이 가장 낮은 시뮬레이션 번호
min_vol_weights = all_weights[min_vol_idx]
min_vol_return  = all_returns[min_vol_idx]
min_vol_vol     = all_volatility[min_vol_idx]

print("\n🔴 [샤프지수 최대 포트폴리오] - 수익 효율이 가장 좋은 조합")
print(f"   수익률  : {max_sharpe_return * 100:.1f}%")
print(f"   변동성  : {max_sharpe_vol * 100:.1f}%")
print(f"   샤프지수: {all_sharpe[max_sharpe_idx]:.2f}")
print("   비중:")
for name, w in zip(name_list, max_sharpe_weights):             # 두 리스트를 쌍으로 묶어 동시에 꺼냄
    print(f"     - {name}: {w * 100:.1f}%")

print("\n🔵 [변동성 최소 포트폴리오] - 가장 안정적인 조합")
print(f"   수익률  : {min_vol_return * 100:.1f}%")
print(f"   변동성  : {min_vol_vol * 100:.1f}%")
print(f"   샤프지수: {all_sharpe[min_vol_idx]:.2f}")
print("   비중:")
for name, w in zip(name_list, min_vol_weights):
    print(f"     - {name}: {w * 100:.1f}%")
plt.figure(figsize=(10, 6))

# 모든 포트폴리오를 점으로 표시 (색상 = 샤프지수)
scatter = plt.scatter(
    all_volatility,
    all_returns,
    c=all_sharpe,
    cmap="viridis",
    alpha=0.5,
    s=5
)
plt.colorbar(scatter, label="Sharpe Ratio")

# 최적 포트폴리오 강조 표시
plt.scatter(max_sharpe_vol, max_sharpe_return,
            color="red", marker="*", s=300, label="Max Sharpe Ratio", zorder=5)
plt.scatter(min_vol_vol, min_vol_return,
            color="blue", marker="*", s=300, label="Min Volatility", zorder=5)

plt.title("Monte Carlo Simulation - Efficient Frontier", fontsize=14)
plt.xlabel("Volatility (Risk)")
plt.ylabel("Expected Return")
plt.legend()
plt.tight_layout()
plt.savefig("monte_carlo_result.png", dpi=150)
plt.show()
##수렴검증

plt.figure(figsize=(12, 6)) #그래프 크기 설정
plt.plot(sharpe_history_iterations, sharpe_history_max_sharpe, color='purple', linewidth=2) # y축 : 최대 샤프지수
plt.title('Maximum Sharpe Ratio Evolution Over Simulations', fontsize=14) # 그래프 제목

모델의 한계

모델 한계

1

과거 의존

과거 평균 수익률과 공분산이 미래에도 유지된다고 가정한다.

2

팻 테일 미반영

실제 금융시장에서는 극단적 급락과 급등이 더 자주 발생할 수 있다.

3

상관관계 고정

위기 상황에서는 자산들이 동시에 하락해 분산 효과가 약해질 수 있다.

4

샤프지수 한계

전체 변동성만 위험으로 보기 때문에 큰 손실 위험을 따로 보지 못한다.

5

근사적 최적화

무작위 후보 중 최선일 뿐, 수학적 전역 최적해를 보장하지 않는다.

6

현실 제약 제외

거래비용, 세금, 유동성, 리밸런싱 비용은 모델에 포함하지 않았다.

실제 금융에서는 어떻게 보완하는가

단순 평균-분산 분석만으로는 예외적 시장 상황의 위험을 과소평가할 수 있다. 그래서 실제 분석에서는 팻 테일, 시간에 따라 변하는 변동성, 하방위험을 함께 반영한다.
